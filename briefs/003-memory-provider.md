## Goal (decided by Ricardo, 2026-09-24)
Replace "inject two capped files into every prompt" with Instinct-style memory: many small typed Markdown
notes in the synced `memory-notes` git folder, a compact profile (USER.md, ~4k tokens) injected every turn,
and everything else found on demand by local search. The same provider runs on the box and inside the
Mac's embedded runtime. Memory never leaves the user's box and devices: no hosted or remote memory, no
network call except the Jev decision URL the policy gives us.

## The note format (`plugins/memory/iollo_notes/notes.py`)
Paths under the memory directory (`tools/memory_tool.get_memory_dir()`): `preferences/`, `people/`,
`organizations/`, `conversations/`, each `<slug>.md` (lowercase ASCII, digits, `-`). USER.md at the root is
generated by the box and read-only here. No dot-prefixed components, no other file types.
```
---
id: people/ana-costa
type: person            # preference | person | organization | conversation
aliases: [Ana, Ana Costa]
updated: 2026-09-24
---
# Ana Costa
- 2026-09-24 Ricardo's dentist in Lisbon, see [[organizations/clinica-sorriso]]. (from: box, whatsapp)
- 2026-09-24 Away until mid-October. {valid_until: 2026-10-15} (from: mac:3f2a, conversation 8c1d)
```
`parse`, `render`, `append_fact(note, text, date, provenance, valid_until=None)`, `slugify`, `links`,
`validate` (header fields present, type matches folder, id matches path, UTF-8, at most 8 KB per note).
Conflict siblings `<stem>.conflict-<sha>.md` are skipped by the parser; the box folds them.

## The index (`plugins/memory/iollo_notes/index.py`)
`$HERMES_HOME/memory-index.db`, outside the git folder, rebuilt incrementally from file mtimes and hashes
on start, after a sync fetch and after every write. Never synced.
1. SQLite FTS5 over title, aliases and bullets (porter tokenizer).
2. sqlite-vec table of one embedding per note (title + aliases + bullets, truncated to the model's window).
   If the extension cannot load, fall back to brute-force cosine in Python (10,000 notes at most, the
   sync layer's cap) and log `vec_fallback` once.
3. Search = reciprocal-rank fusion of FTS and vector hits, then one hop: notes whose aliases match the
   query terms and notes `[[linked]]` from the top hits join with a lower weight. Return id, type, title,
   score and the three best-matching bullets.
Embedding model, **flagged for the owner**: `sentence-transformers/all-MiniLM-L6-v2`, int8 ONNX (about
23 MB, 384 dimensions), run with the `onnxruntime==1.27.0` pin the `wake` extra already uses. It is the
smallest widely used sentence model that runs on the box CPU and on Apple silicon; `BAAI/bge-small-en-v1.5`
(about 34 MB, same dimensions) is the step up if recall is poor. Ship the file inside the release artifacts
(box image and Mac runtime) with its SHA-256 pinned in `plugins/memory/iollo_notes/model.json`; never
download at runtime. New extra `iollo-memory = ["onnxruntime==1.27.0", "sqlite-vec", "tokenizers"]`, each
pinned, installed into the box image and both Mac runtimes by `scripts/iollo/`.

## The provider (`plugins/memory/iollo_notes/__init__.py`, `plugin.yaml`)
Named `iollo_notes` (the directory name is the provider name), activated by `memory.provider: iollo_notes`.
Settings (via `get_config_schema`): `decide_url`, `decide_token_env` (the relay bearer env on the box,
the device credential on the Mac),
`decide_timeout_s` (default 1.5), `device` (`box` or `mac:<id>`).
1. `system_prompt_block`: USER.md verbatim, capped at 16,000 characters, in the same fenced block style
   `MemoryStore._render_block` uses; if absent, a one-line "no profile yet". Nothing else is injected
   whole: the built-in MEMORY.md/USER.md injection is off because the policy sets both built-in flags false.
2. `prefetch(query)`: skip `is_trivial_prompt`; POST `{decision: "retrieve"}` to `decide_url`; if Jev says
   no, return "". If yes or no answer, search, POST `{decision: "rerank"}` with the top 10, keep the top 3
   (fused order when Jev gives no answer) and return them through `build_memory_context_block`.
3. Tools (`get_tool_schemas` / `handle_tool_call`):
   - `memory_search(query, type?, limit=5)` → hits as above.
   - `memory_read(id)` → the whole note plus the ids it links to.
   - `memory_note(fact, type_hint?, about?, valid_until?)` → search for candidates, POST
     `{decision: "route"}`, append a dated bullet with provenance (`device`, session id) to the chosen note
     or create a new one; fallback: best hit above a fixed score, else a new note of `type_hint`. Returns the
     note id. Writes go through a file lock and are atomic (temp file + rename).
4. `on_memory_write`: a legacy `memory` tool write (older profiles) becomes a `memory_note` call.
5. Tool descriptions say plainly: search before claiming not to know; record facts with `memory_note`;
   USER.md is generated, do not try to edit it.

## Tests (`tests/plugins/memory/test_iollo_notes_*.py`, the style of the holographic tests)
- Format: round-trip parse/render; `validate` rejects a wrong folder, a missing id, dot paths, 9 KB notes;
  conflict siblings are skipped.
- Index: FTS finds by alias; the vector path finds a paraphrase ("my dentist" → `people/ana-costa`) with a
  small fake embedder, and with the real model when the extra is installed (skip otherwise); one hop adds a
  linked note; the fallback works with sqlite-vec disabled; incremental rebuild after a file changes.
- Provider with a stub decide server: retrieve no → no context; retrieve yes → top 3 reranked;
  decide down or slow → fused order within the timeout; `memory_note` routes to the chosen note, creates a
  new one on `new:person`, stamps provenance, keeps valid UTF-8 under concurrent writes.
- With `memory.provider` unset the whole existing suite is unchanged (the default).

## Acceptance
On a local profile with a fixture notes folder and a stub decide URL: the system prompt contains USER.md
and no other note; asking "what did I say about Ana?" makes the agent call `memory_search`, and the answer
comes from `people/ana-costa.md`; `memory_note("prefers morning appointments", about="Ana")` adds one
dated bullet with provenance to that note.
